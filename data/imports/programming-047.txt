Tips για τους μαθητές:

   1. Η Δομή των Loops:
         ▪ Το εξωτερικό for i in range(N-1) καθορίζει πόσα στοιχεία θα έχουν
           "τακτοποιηθεί" στις σωστές τους θέσεις.
         ▪ Το εσωτερικό for j in range(N-1, i, -1) είναι αυτό που κάνει την πραγματική
           δουλειά. Ξεκινάμε από το τέλος (N-1) και σταματάμε στο i+1 (το range
           σταματάει ένα πριν το i).
   2. Η "Μαγεία" της Ανταλλαγής:
         ▪ Έχουμε δείξει για την ανταλλαγή και την χρήση της temp. Στην Python
           εξηγούμε ότι η εντολή a, b = b, a κάνει την ανταλλαγή αυτόματα και είναι
           πολύ πιο εύκολη.
   3. Αύξουσα vs Φθίνουσα:
         ▪ Τονίζουμε ότι αν αλλάξουμε το < σε > στη συνθήκη if A[j] < A[j-1], ο
           αλγόριθμος θα κάνει φθίνουσα ταξινόμηση.
   4. Οπτικοποίηση:
         ▪ Αυτό που δείχνει ο πίνακας της άσκησης είναι ότι στο 1ο πέρασμα το -2
           (το ελάχιστο) "κολυμπάει" μέχρι την πρώτη θέση. Στο 2ο πέρασμα, το 3
           "κολυμπάει" μέχρι τη δεύτερη θέση, και ούτω καθεξής.

# --- Δ4: Συνάρτηση Αναζήτησης ---
def anazitisi(key, CODE):
    pos = -1 # Αρχικοποίηση θέσης στο -1 (δεν βρέθηκε)
    i = 0
    n = len(CODE) # Μήκος της λίστας
    while i < n and pos == -1:
        if CODE[i] == key:
            pos = i # Βρέθηκε ο κωδικός στη θέση i
        else:
            i = i + 1
    return pos # Επιστροφή θέσης ή -1
