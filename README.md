# Μαθήματα / εξάσκηση ΕΠΑΛ

Στατική εφαρμογή vanilla JavaScript / HTML / Tailwind CSS με ανεξάρτητες τράπεζες μαθημάτων. Λειτουργεί τοπικά με διπλό κλικ στο `index.html`, χωρίς Internet ή εγκατάσταση εργαλείων, και σε Netlify.

## Περιεχόμενο

- Δίκτυα Υπολογιστών: 236 εγγραφές, εξετάσεις 2009–2026.
- Προγραμματισμός Υπολογιστών: 116 εγγραφές Python, εξετάσεις 2017–2026. Όλα τα θέματα Pascal έχουν αφαιρεθεί από την εφαρμογή και το πακέτο διανομής. Τα πρωτότυπα αρχεία στους φακέλους μαθημάτων δεν μεταβλήθηκαν.

Οι λύσεις βασίζονται στα παρεχόμενα PDF απαντήσεων. Κάθε ερώτηση έχει παραπομπή στο σχετικό αρχείο. Στα Δίκτυα οι προηγούμενες επεξηγήσεις του βιβλίου διατηρούνται όπου χρειάζονται ως συμπληρωματική τεκμηρίωση. Παλιότερα αρχεία λύσεων που παραπέμπουν σε παλιό βιβλίο χωρίς πλήρες κείμενο δεν παρουσιάζονται ως αυτούσια απάντηση του τωρινού βιβλίου.

Οι απαντήσεις είναι ενδεικτικές, όχι επίσημο κλειδί βαθμολόγησης. Σε διαφωνίες ή γνωστές ασάφειες εμφανίζεται σημείωση και εξαιρείται η αυτόματη βαθμολόγηση. Τα PDF παραμένουν διαθέσιμα για ακριβή μορφοποίηση πινάκων και κώδικα.

## Χρήση

Διάλεξε τομέα/ειδικότητα και μάθημα. Συνδύασε κεφάλαια, ακριβείς παραγράφους, εξεταστέα ύλη από το αντίστοιχο `Υλη.md`, έτος και τύπο ερώτησης.

Η τρέχουσα εφαρμογή εμφανίζει μόνο θέματα Πανελλαδικών. Δεν υπάρχουν φίλτρα τετραδίων, δικών μας ερωτήσεων ή ετικετών. Το σχήμα δεδομένων διατηρεί τη δυνατότητα μελλοντικής επέκτασης, χωρίς να ενεργοποιεί αυτές τις πηγές στο quiz.

Η λειτουργία «Ανά έτος» ανοίγει συγκεκριμένη ολόκληρη εξέταση και αγνοεί τα φίλτρα ελεύθερης εξάσκησης. Υποστηρίζονται πολλαπλές συλλογές εξετάσεων ανά έτος. Ερωτήσεις τετραδίου ή καθηγητή μπορούν να μην έχουν έτος.

Σωστό/λάθος και πολλαπλής επιλογής διορθώνονται άμεσα. Αντιστοίχιση, συμπλήρωση και υπολογισμοί διορθώνονται με το κουμπί ελέγχου. Στην ανάπτυξη/συγγραφή προγράμματος δεν απαιτείται input: εμφάνισε τη λύση ή προχώρησε όποτε θέλεις.

Στον Προγραμματισμό εφαρμόζεται η Python 2 του βιβλίου. Τα κενά κώδικα ελέγχουν και τα κεφαλαία/πεζά· δεν εκτελείται κώδικας μαθητή ή κώδικας από PDF. Τα πλήρη προγράμματα παραμένουν ερωτήσεις μελέτης.

Τα λάθη διατηρούνται χωριστά ανά μάθημα για την τρέχουσα επίσκεψη. Η αλλαγή μαθήματος ξεκινά νέο σετ και η ανανέωση σελίδας μηδενίζει όλη την πρόοδο. Το ποσοστό επιτυχίας αφορά τις ερωτήσεις που ελέγχθηκαν και δεν είναι βαθμός Πανελλαδικών.

## Τοπικά και Netlify

Για τοπική χρήση, κράτησε μαζί όλα τα αρχεία της εφαρμογής και άνοιξε `index.html`.

Για Netlify, αποσυμπίεσε το `diktya-quiz-netlify.zip` του γονικού φακέλου και ανέβασε τον φάκελο που περιέχει απευθείας το `index.html`. Δεν απαιτείται build στη φιλοξενία. Για αποθετήριο, base directory `diktya-quiz`, publish directory `.`. Δεν έχει πραγματοποιηθεί δημοσίευση σε λογαριασμό Netlify.

## Συντήρηση και επέκταση

Δες το [σχήμα δεδομένων και οδηγίες προσθήκης περιεχομένου](docs/CONTENT.md). Νέα μαθήματα και ειδικότητες προστίθενται με δεδομένα. Τετράδια και δικές μας ερωτήσεις απαιτούν μελλοντική ενεργοποίηση στο UI· προς το παρόν δεν εμφανίζονται, ακόμη κι αν υπάρχουν στην τράπεζα.

Προαιρετικά εργαλεία ανάπτυξης: Node.js/npm, Python 3. Τα εργαλεία δεν απαιτούνται για τη χρήση της έτοιμης εφαρμογής.

```sh
npm ci
npm run build:data
npm run build:css
npm test
npx playwright install chromium
npm run test:browser
npm run package
npm run serve
```

Ο τοπικός server ακούει στο `http://localhost:8080`. Το `build:data` ελέγχει όλα τα μαθήματα πριν γράψει τα offline scripts. Το `package` παράγει ZIP με τις ενεργές τράπεζες και μόνο τις χρησιμοποιούμενες πηγές.

Οι δοκιμές ελέγχουν τη βαθμολόγηση, μαθηματικούς υπολογισμούς, ακριβή σύγκριση κώδικα, φίλτρα νέων συλλογών, απομόνωση μαθημάτων, όλες τις 352 κάρτες, τοπικό άνοιγμα `file://`, HTTP και κινητή οθόνη.
